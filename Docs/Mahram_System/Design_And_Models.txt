Simplified System Block Diagram

Overview: The platform consists of a Next.js client with edge middleware, a server/API layer, a Supabase backend (Auth + Postgres with RLS and PL/pgSQL), and an external safety analysis API. Privacy is enforced at the data tier via Mahram-aware policies; safety analysis is performed server-side via a latency-bounded pipeline.

Notes
- Privacy enforcement is performed at the database layer via RLS and Mahram-aware policies; UI scopes reflect, but do not replace, data-tier guarantees.
- Safety analysis runs server-side (API route) with rate limiting and timeouts; the client receives categorized guidance rather than raw scores.
- Domain workflows (friend graph, notifications, incentives) are implemented via PL/pgSQL functions/RPCs and triggers.
